# 🧟 Zombie Chase

A Python/Pygame survival game set in a mysterious jungle covered by fog.

Navigate through the dangerous environment, complete tasks, avoid pursuing zombies, and reach the portal before it's too late. Choose your difficulty, manage your stamina, and survive the fog of war.

## 🎮 Features

- 🌲 Procedurally generated jungle environment
- 🧟 Zombie enemies with BFS pathfinding
- 🌫️ Dynamic fog-of-war system
- 💡 Lamps and torch-based visibility
- 🎯 Task-based objectives
- 🌀 Portal and shadow-realm mechanic
- ❤️ Health and stamina systems
- ⏱️ Multiple difficulty modes and time limits
- ✨ Particle effects including mist, sparks, and blood
- 🎮 Keyboard and on-screen controls
- 🔄 Restart and main-menu functionality

## 🛠️ Technologies

- Python
- Pygame
- BFS Pathfinding
- Object-oriented game architecture

## 🎯 Difficulty Modes

### 🟢 Easy

Explore freely with no time limit.

### 🟡 Medium

Choose a time limit between 2–3 minutes.

### 🔴 Hard

A fast-paced challenge with 40–60 second time limits, faster zombies, and denser fog.
